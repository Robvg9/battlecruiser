# Ventas — Referencias UX

Esta carpeta está destinada a capturas, referencias visuales y propuestas de diseño de la pantalla de Venta.

## Captura actual
Subir aquí la captura real de la pantalla de Venta que se utilizará como referencia forense antes de implementar el rediseño.

## Propuesta
La pantalla objetivo debe priorizar:
- barra superior fija;
- contexto de almacén/sesión siempre visible;
- búsqueda y filtros accesibles sin mover el layout principal;
- catálogo como único scroll principal;
- carrito estable, sin scroll exterior innecesario;
- total y acciones de venta siempre visibles;
- uso extremadamente rápido por la dependienta durante una jornada completa.

No modificar código de Venta desde esta carpeta.
